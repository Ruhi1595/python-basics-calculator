# Python Calculator 

A beginner-friendly Python calculator built in a Jupyter Notebook to practice core programming concepts:
- **User Input & Type Casting:** Handling whole and decimal numbers (`float`).
- **Control Flow:** Conditional branching (`if / elif / else`) for `+`, `-`, `*`, and `/`.
- **Edge Case Handling:** Preventing zero-division errors.
